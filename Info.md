chips.gg Stream Tracker

A clean, minimal web app to log and track my stream cashouts on chips.gg.

What it does
Log every stream session with the date, stream name, and cashout amount
Tracks total net cashout, best session, and worst session
Marks each session as profit or loss
Export all data to CSV anytime
Data is saved to the cloud — works on any device, any browser
Stack
Vanilla HTML / CSS / JS — no frameworks
Supabase (PostgreSQL) for cloud data storage
Hosted on Netlify
Why I built it

Wanted a dead-simple way to keep track of my streamer's stream without digging through spreadsheets or notes. One page, no login, just open the link and log your session.
